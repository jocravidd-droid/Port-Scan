### The `scan` Method

```python
async def scan(self):
    tasks = [scan_port(...) for port in self.port_range]
    result = await asyncio.gather(*tasks)
    save = [p for p in result if p is not None]
```

This asynchronous method executes in three distinct steps[cite: 4]:

1. **Task Generation:** A list comprehension creates a coroutine for every port in the range[cite: 4]. At this stage, nothing runs; calling an `async def` function simply returns a pending coroutine[cite: 4].
2. **Concurrent Execution:** `asyncio.gather(*tasks)` launches all these pending coroutines simultaneously[cite: 4]. The asterisk (`*`) unpacks the list into separate arguments[cite: 4].
3. **Result Filtering:** `gather` returns the results in the exact order of the original list[cite: 4]. The comprehension filters out `None` values (closed ports), keeping only the open ones[cite: 4].

## The `scan_port` Function

```python
async def scan_port(target, port, timeout_value, semaphore):
    async with semaphore:
        try:
            conn = asyncio.open_connection(target, port)
            _reader, writer = await asyncio.wait_for(conn, timeout=timeout_value)
            writer.close()
            await writer.wait_closed()
            return port
        except (asyncio.TimeoutError, ConnectionRefusedError, OSError):
            return None
```

The `async with semaphore` block restricts execution if the maximum number of simultaneous connections is reached[cite: 4]. The semaphore is automatically released when the block exits, even if an error is raised[cite: 4].

`asyncio.open_connection` creates a coroutine without executing it immediately; `asyncio.wait_for` launches it and enforces the timeout parameter[cite: 4]. 

The `_reader` variable is unpacked but left unused (the underscore signifies this in Python)[cite: 4]. The `close()` method requests termination, and `wait_closed()` asynchronously waits for the connection to fully shut down[cite: 4].
