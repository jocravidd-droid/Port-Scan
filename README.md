## What It Does

This script tests a defined range of ports on a specific target (an IPv4 address or a domain name) and displays the open ports alongside their associated service names (e.g., SSH, HTTP, MySQL)[cite: 5].

It strictly validates the format of the target input using regular expressions[cite: 5]. When a domain name is provided, the script extracts the domain extension (TLD) and cross-references it with an internal database to display the domain's intended type and usage[cite: 5].

Instead of hardcoding values, the script interactively prompts the user for all necessary parameters: the target, starting port, ending port, timeout duration, and the maximum number of simultaneous connections[cite: 5].

The program runs in a continuous loop: after a scan concludes, it immediately asks for a new target[cite: 5]. Typing `exit` will cleanly terminate the application[cite: 5].

## How It Works Under the Hood

Every individual port is tested by a dedicated coroutine named `scan_port`[cite: 5]. This coroutine attempts to establish a connection using `asyncio.open_connection` and applies the user-defined timeout via `asyncio.wait_for`[cite: 5]. If the connection succeeds, the port number is returned[cite: 5]. If the connection fails due to a timeout, refusal, or network error, it safely returns `None`[cite: 5].

The main `scan` method builds a list of coroutines for every port in the specified range and launches them concurrently using `asyncio.gather`[cite: 5]. The closed ports (represented by `None`) are then filtered out of the final list[cite: 5].

At the end of the scan, the script cross-references the discovered open ports with the `ports_services_complet` dictionary to format the terminal output with highly readable service names (defaulting to "Unknown service" if the port is unlisted)[cite: 5].

To protect the host system, an `asyncio.Semaphore` restricts the number of connections opened simultaneously, preventing the scanner from exceeding the operating system's file descriptor limit[cite: 5].

## Logging System

The application robustly handles several edge cases and user errors[cite: 5]:
